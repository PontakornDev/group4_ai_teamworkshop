    4. Determine mostDisliked: same logic with dislikeCount.
    5. Return { mostLiked, mostDisliked } — each is either a shaped object or null.

    Do NOT import any new modules. Do NOT use Array.sort() for tie-breaking — use a single-pass reduce or forward iteration to preserve first-encountered stability.
