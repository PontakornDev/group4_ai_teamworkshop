## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo → public GitHub | Anything committed becomes world-readable; secrets must not cross |
| GitHub → Vercel build | Build env reads Vercel dashboard env vars, not committed files |
| browser → Vercel app | Google OAuth callback must match registered redirect URI |
