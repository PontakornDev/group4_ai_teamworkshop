Output: Recorded production URL in summary; verified working sign-in / swipe / history loop.
</objective>

<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Human deploys to Vercel and configures env vars + OAuth redirect</name>
  <what-built>
    Repo is verified ready for Vercel import (Task 1 passed). README documents the deploy steps and OAuth configuration.
  </what-built>
  <how-to-verify>
    Follow the README.md "Deploy to Vercel" section in order:

    1. Push the current branch to GitHub: `git push origin main` (if not already pushed).
    2. Go to https://vercel.com → "Add New" → "Project" → import the GitHub repo.
    3. Framework preset is auto-detected as Next.js — accept defaults.
    4. Before the first deploy, in Vercel → Settings → Environment Variables (Production scope), add:
       - `CLIENT_ID` = your Google OAuth client id
       - `CLIENT_SECRET` = your Google OAuth client secret
       - `NEXTAUTH_SECRET` = output of `openssl rand -base64 32`
       - `NEXTAUTH_URL` = `https://your-project.vercel.app` (placeholder for now — will update in step 7)
    5. Click "Deploy". Wait for the build to finish.
    6. Copy the actual assigned Vercel URL (e.g. `https://group4-ai-teamworkshop.vercel.app`).
    7. In Vercel → Settings → Environment Variables, edit `NEXTAUTH_URL` to the exact URL from step 6 (no trailing slash).
    8. Go to Google Cloud Console → APIs & Services → Credentials → OAuth 2.0 Client → edit. Under "Authorized redirect URIs", ADD `https://<your-vercel-url>/api/auth/callback/google`. Keep the existing `http://localhost:3000/api/auth/callback/google` entry. Save.
    9. Back in Vercel → Deployments → click the latest deployment → "Redeploy" (so the new NEXTAUTH_URL takes effect).
    10. Once the redeploy finishes, paste the production URL back here so verification can resume.
  </how-to-verify>
  <resume-signal>
    Reply with the production URL (e.g. `https://group4-ai-teamworkshop.vercel.app`) OR describe what failed and at which step.
  </resume-signal>
</task>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Vercel app | All session creation and dog-image traffic crosses this boundary |
| Vercel build → Google OAuth | Production redirect URI must match registered URI exactly |
| user keyboard → Vercel dashboard | Env var values entered manually; copy/paste error risk |
