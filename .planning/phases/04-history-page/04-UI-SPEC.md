## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline tight spacing |
| sm | 12px | Card internal padding (mobile list), pill tab padding, avatar gaps |
| md | 24px | Card internal padding (desktop grid), section gaps, sidebar padding |
| lg | 40px | Desktop page top padding, major section breaks |
| xl | 64px | Page bottom padding (mobile nav clearance) |
| container-padding | 20px | Horizontal page gutters (mobile + desktop) |
| card-gutter | 16px | Grid gap between desktop cards |
| base | 8px | Nav item spacing, stacked list rhythm |

Exceptions:
- Mobile top nav height: 64px (h-16) — fixed by existing Navbar.tsx
- Mobile circular dog thumbnail: 64px (w-16 h-16) — fixed by existing HistoryList.tsx
- Desktop circular dog thumbnail: 128px (w-32 h-32) — fixed by existing HistoryList.tsx
- Summary bar stat chip min-touch-target: 44px height minimum for accessibility

Source: `app/globals.css` spacing tokens; `design/pawnder_history_mobile/code.html` and `design/pawnder_history_desktop/code.html` spacing patterns; existing `components/HistoryList.tsx`.

## Interaction Contract

### Filter Pills (All / Likes / Dislikes)

- Default state: "All" active
- Click: updates `filter` state in `useState` — client-side only (no URL params, per D-09)
- No animation required; instant class swap from inactive to active pill style
- Scroll-overflow on mobile: `overflow-x-auto no-scrollbar` wrapping div

### Sort Dropdown (Newest / Oldest)

- Default: "Newest first"
- Implemented as native `<select>` element
- Sorts by `myEntry.timestamp` (the current user's col entry timestamp for each dog)
- Sort is applied after filter

### Summary Bar Chips

- Three chips always visible: total swiped, total likes, total dislikes
- All counts scoped to current user's records only (D-06)
- Sticky below page title on mobile (top-16 to clear Navbar), non-sticky on desktop
- No click interaction — display only

### Dog Cards

- Mobile: flex row list — `hover:shadow-md transition-shadow`
- Desktop: grid card — `hover:shadow-lg hover:-translate-y-1 transition-all duration-300`
- No click-through action (no per-dog detail page in Phase 4 scope)
- Image: `next/image` with `unoptimized` (same pattern as existing HistoryList.tsx)

### Empty States

Two distinct empty states:

1. Global empty (no swipes at all for this user):
   - Icon: `pets` Material Symbol (filled: 0), 40px display size
   - Heading: "No swipes yet" — `text-headline-md`
   - Body: "Start swiping to see your history here." — `text-body-md`
   - Already implemented in HistoryList.tsx — do not change

2. Filtered empty (user has swipes but filter returns zero):
   - Icon: `filter_list` Material Symbol, 40px
   - Heading: "No [Likes / Dislikes] found" — `text-headline-md` (interpolate filter label)
   - Body: "Try switching to All to see your full swipe history." — `text-body-md`

### Error State

- If `/history` page fails to load records (storage read error), show:
  - Heading: "Couldn't load history" — `text-headline-md text-on-surface`
  - Body: "Something went wrong reading swipe records. Refresh the page to try again." — `text-body-md text-on-surface-variant`
- Displayed in the main content area in place of the list/grid
- No destructive actions in Phase 4

### Destructive Actions

None. Phase 4 has no delete, reset, or irreversible operations.
